# 🚀 Motivational AI App

O **Motivational AI App** é um aplicativo interativo desenvolvido em **React Native**, que utiliza **OpenRouter AI** para gerar mensagens motivacionais com base na entrada do usuário. 📲✨

---

## 📌 **Recursos**
✔️ Interface intuitiva e responsiva 📱  
✔️ Integração com **OpenRouter AI** para geração de respostas 🌐  
✔️ Design moderno com tema escuro 🎨  
✔️ Input interativo com teclado ocultável ⌨️  
✔️ Ícone minimalista para uma experiência mais clean 🔥  

---

## 🛠️ **Tecnologias Utilizadas**
- **React Native** ⚛️
- **Expo** 🏗️
- **Axios** 🌍
- **react-native-dotenv** 🔑
- **OpenRouter AI API** 🤖
